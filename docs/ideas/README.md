# Ideas log

One numbered file per idea that came out of a Fable 5 brainstorming chat —
per the notes' "each idea gets its own numbered .md, don't dump everything
in one file" rule. Name files `NN-short-slug.md`, numbered sequentially.

This keeps ideation output separate from the architecture/decision docs one
level up: a file in here is a raw idea, possibly not yet acted on. Once an
idea is actually implemented, it should get referenced from
[STRUCTURE_CHANGELOG.md](../STRUCTURE_CHANGELOG.md) or folded into
[ARCHITECTURE.md](../ARCHITECTURE.md) as the decision it became — the file
here stays as the historical record of why.
